# Stream notifier bot

Telegram-бот отправляет в выбранные группы уведомления о начале Twitch, YouTube,
Kick, VK, Rutube, Instagram и TikTok-эфиров. Каналы добавляются в личке с ботом, а группа для уведомлений
выбирается кнопкой.

## Структура проекта

```text
bot.py              # точка входа BotHost, Telegram-обработчики и планировщик
config.py           # переменные окружения и интервалы опроса
constants.py        # адреса API, названия платформ и настройки интерфейса
models.py           # модели предметной области
database.py         # SQLite-хранилище, схема и миграции
providers.py        # API-клиенты, URL и разбор публичных страниц площадок
notifications.py    # формирование клавиатур и отправка уведомлений
test_public_urls.py # тесты URL и HTML-парсеров
```

На BotHost точка запуска остаётся прежней: `python -u bot.py`. Dockerfile
копирует все Python-модули, поэтому дополнительные настройки запуска не требуются.

## Переменные окружения

Скопируйте `.env.example` в секреты хостинга и заполните:

- `BOT_TOKEN` — токен от [BotFather](https://t.me/BotFather).
- `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` — приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps).
- `KICK_CLIENT_ID` и `KICK_CLIENT_SECRET` — данные приложения из
  [Kick Developer Portal](https://kick.com/settings/developer).
- `INSTAGRAM_COOKIE`, `TIKTOK_COOKIE` и `STREAM_PROXY_URL` — необязательные
  настройки для серверных запросов к публичным страницам. Cookie берётся из
  заголовка `Cookie` в инструментах разработчика браузера после входа в аккаунт.
  Не передавайте её третьим лицам и не коммитьте в репозиторий.

YouTube, VK, Rutube, Instagram и TikTok проверяются по публичным страницам, поэтому
ключи API для них не нужны. Это менее стабильно, чем API: площадки могут менять
разметку или ограничивать запросы. При переходе на официальные API ключи создаются
в [VK ID](https://id.vk.com/about/business/go/docs/ru/vk-id/latest/vk-id/overview),
[Rutube Studio](https://studio.rutube.ru/), [Meta for Developers](https://developers.facebook.com/)
и [TikTok for Developers](https://developers.tiktok.com/).

База SQLite хранится в `DB_PATH`. Для Docker смонтируйте `/app/data` как постоянный том, иначе состояние подписок будет потеряно при пересоздании контейнера.

## Веб-кабинет

После запуска бот также поднимает публичный сайт на `WEB_PORT` (по умолчанию
`8080`). Это пользовательский кабинет, а не панель администратора: каждый
вошедший Telegram-пользователь видит только свои личные подписки и чаты,
доступ к которым сохранён в `chat_access`.

Веб-кабинет позволяет выбрать режим, добавлять, проверять и удалять подписки,
настраивать оформление и кнопки, вести недельное расписание с локальной
картинкой, смотреть предпросмотр и публиковать расписание в Telegram.

Вход использует Telegram Login: сервер проверяет HMAC-подпись Telegram, затем
выдаёт `HttpOnly`, `SameSite=Lax` cookie. Изменяющие запросы дополнительно
защищены CSRF-токеном. Не устанавливайте `WEB_COOKIE_SECURE=0` на публичном
сайте: это значение допустимо только для локальной отладки по HTTP.

### Действия, которые остаются в Telegram

- Добавьте бота администратором в канал или группу. Telegram пришлёт событие
  боту, и этот чат появится в селекторе сайта.
- Список тем форума Bot API не предоставляет. Откройте нужную тему и отправьте
  в ней `/topic` для уведомлений либо `/schedule_topic` для расписания.
- Telegram custom emoji в inline-кнопках требуют специальный ID, который веб
  браузер не получает. Отправляйте такой emoji боту при настройке; Unicode emoji
  можно указать на сайте.
- Картинка расписания, загруженная с сайта, хранится в `WEB_UPLOAD_DIR` и
  отображается в кабинете. У неё нет Telegram `file_id`; при публикации сайт
  отправляет локальный файл. Картинки оформления, загруженные через бота, по
  Telegram `file_id` в браузере не отображаются.

### Развёртывание на BotHost / Docker

1. Соберите новый образ из этой папки. Dockerfile копирует `static/` и создаёт
   `/app/data/web_uploads`.
2. Подключите постоянный том хостинга к `/app/data`: в нём лежат SQLite-файл,
   WAL-файлы и загруженные картинки.
3. Укажите секреты из `.env.example`, обязательно добавив:

   ```env
   WEB_ENABLED=1
   WEB_PORT=8080
   WEB_COOKIE_SECURE=1
   TELEGRAM_LOGIN_BOT_USERNAME=your_bot_username
   DB_PATH=/app/data/streams.db
   WEB_UPLOAD_DIR=/app/data/web_uploads
   ```

4. В настройках BotHost опубликуйте HTTP-порт `8080` и направьте на него
   HTTPS-домен, например `https://streams.example.com`.
5. В BotFather используйте `/setdomain`, выберите этого бота и укажите тот же
   домен без пути: `streams.example.com`. Без этого Telegram Login не покажет
   кнопку входа.
6. Оставьте команду запуска `python -u bot.py`. Polling и FastAPI работают в
   одном контейнере; не запускайте второй экземпляр с той же базой.
7. Откройте HTTPS-домен, войдите тем же Telegram-аккаунтом, добавьте бота
   администратором в тестовый чат и убедитесь, что чат появился в кабинете.

Для локальной проверки можно выставить `WEB_COOKIE_SECURE=0`, запустить
`python -u bot.py` и открыть `http://127.0.0.1:8080/`. Не используйте эту
настройку в production.

## Настройка в Telegram

1. При первом запуске выберите режим:
   - **Стример** — настройка уведомлений в своих группах и каналах.
   - **Подписчик** — добавление стримеров для личного отслеживания; уведомления
     о старте эфиров приходят в личный чат с ботом.
   Режим можно изменить кнопкой **Режим**.
2. В режиме стримера добавьте бота администратором в нужный канал или группу. Для этого не нужно
   писать никаких команд в самом канале: бот автоматически запомнит чат в момент
   добавления.
   Если это Telegram-форум, откройте нужную тему и отправьте в ней `/topic`.
   Бот запомнит тему и будет отправлять уведомления именно туда. Список тем
   получить через Telegram Bot API нельзя, поэтому выбор выполняется внутри
   самой нужной темы.
3. Откройте личный чат с ботом и используйте появившееся меню:
   - **Добавить канал** — выбрать Twitch, YouTube или Kick, прислать ссылку и
     выбрать получателя уведомлений.
   - **Мои подписки** — открыть сведения о канале или удалить его с
     подтверждением.
   - **Проверить эфиры** — выполнить проверку немедленно.
   - **Оформление** — изменить заголовок и описание уведомления, загрузить свою
     картинку или удалить её, добавить любые кнопки со ссылками (включая
     Discord), выбрать источник автоматического превью, включить блюр, посмотреть
     текущие настройки, выбрать эмодзи и цвет кнопок или отправить себе пример
     уведомления.
     При добавлении кастомной кнопки укажите номер строки: кнопки с одинаковым
     номером будут показаны в одной группе.
     Кастомные эмодзи можно отправить боту при настройке кнопки. Для их показа
     владелец бота должен иметь Telegram Premium либо бот должен иметь
     дополнительный username, купленный на Fragment.
     Для кнопок доступны встроенные стили Telegram: синий, зелёный и красный.
4. В описание можно добавить правила, ссылки и другую постоянную информацию;
   оно будет показано над списком начавшихся эфиров. При изменении заголовка
   и описания доступны подстановки `{count}` — число новых эфиров, и `{time}` —
   время начала эфира по Москве.
   Для каждой платформы также доступны название и категория: `{titleYT}`,
   `{titleTwich}`, `{titleKick}`, `{categoryYT}`, `{categoryTwich}`,
   `{categoryKick}`. Написание `{titleTwitch}` и `{categoryTwitch}` также
   поддерживается.
5. Чтобы отменить незавершённый шаг, нажмите **Отмена** в нижнем меню.

Команды `/add`, `/chats`, `/list`, `/remove`, `/check`, `/template` и
`/preview` сохранены как запасной вариант.

Для Kick добавьте канал через меню либо командой:
```
/add kick https://kick.com/streamer
```

Первый опрос после добавления запоминает текущий статус канала, но не уведомляет об уже идущем эфире. Уведомление придёт при следующем переходе канала из офлайна в эфир.

Twitch и Kick проверяются каждые 90 секунд, YouTube — каждые 300 секунд.
Уведомление отправляется сразу после обнаружения нового эфира. Если второй
эфир будет обнаружен позднее, бот отредактирует уже отправленное уведомление,
добавив информацию о нём. Уведомление содержит загруженную через
`/preview` картинку. Для автоматического превью можно выбрать Twitch, YouTube,
Kick или автовыбор. Twitch-карточка содержит превью эфира, аватар стримера и
обложку игры; при блюре аватар и обложка категории остаются чёткими. Для
YouTube и Kick блюр применяется к фону превью.

## Лимиты YouTube

Проверка YouTube использует `search.list` с фильтром `eventType=live`; этот
вызов расходует API-квоту Google. При большом количестве YouTube-каналов
увеличьте `YOUTUBE_POLL_INTERVAL_SECONDS` и проверьте квоту проекта в Google
Cloud Console.
